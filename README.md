# ☕ SONSUZ ÇAY BEKLEME PROTOKOLÜ ☕

## Giriş (Abartılı ve Ciddi)

Bu repository, insanlığın en büyük sorunlarından biri olan **çay bekleme süresi** sorununu çözmek için geliştirilmiştir. Bilimsel araştırmalar (uydurulmuş) gösteriyor ki ortalama bir Türk vatandaşı ömrünün %47.3'ünü çay demlenmesini bekleyerek geçirmektedir. Bu protokol, bu süreyi optimize etmek yerine **bilinçli olarak uzatarak** felsefi bir boyut kazandırmayı amaçlar.

### Özellikler
- Gerçekten çalışır (Python 3+ gerektirir)
- Sonsuza yakın bekleme süresi (veya en azından 10-60 saniye)
- Rastgele Türkçe felsefi çay sözleri üretir
- Hiçbir şey yapmaz ama yapıyormuş gibi yapar
- Gizli bir mesaj içerir (bulamazsın)

### Kurulum ve Kullanım

```bash
git clone https://github.com/Tentivory/sonsuz-cay-bekleme-protokolu.git
cd sonsuz-cay-bekleme-protokolu
python3 cay_bekle.py
```

### Uyarı
Bu yazılım çayınızı gerçekten demlemez. Sadece bekletir. Çay içmek istiyorsanız mutfağa gidin. Bu bir simülasyondur. Gerçek çay zarar görebilir.
